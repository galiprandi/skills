# Calendly — validated 2026-10-22

Prerequisite: read parent `SKILL.md`.

## Flow

1. Click the date button (day number) on the calendar grid.
2. Set timezone FIRST: click the "Time zone" row → list opens → find `<city> Time` option and click it. Defaults to UTC otherwise.
3. Click the slot button (`HH:MM`).
4. Click `Next` → fill `Name *`, `Email *`, notes textarea → click `Schedule Event`.
5. Verify: "You are scheduled!" + invite sent text.
